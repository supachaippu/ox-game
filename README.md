# 🎮 Web Application เกม OX (Tic-Tac-Toe) พร้อมระบบ OAuth 2.0 & Cloudflare D1

โปรเจกต์นี้เป็นเว็บแอปพลิเคชันสำหรับเล่นเกม OX (Tic-Tac-Toe) แข่งกับบอท พัฒนาด้วย **Next.js (App Router)**, **TypeScript** และจัดแต่งสไตล์อินเทอร์เฟซแบบพรีเมียมด้วย **Vanilla CSS** โดยระบบหลังบ้าน API รันอยู่บน **Cloudflare Pages (Edge Runtime)** และบันทึกข้อมูลถาวรลงฐานข้อมูลคลาวด์จริง **Cloudflare D1 (SQLite Database)** เพื่อความรวดเร็วและปลอดภัยสูงสุด ออกแบบตามหลัก Clean Code และการทดสอบซอฟต์แวร์ (Unit Testing)

---

## ✨ คุณสมบัติเด่นของโครงการ (Key Features)

1.  **🔌 ระบบล็อกอิน OAuth 2.0 (Hybrid Mode):**
    *   **GitHub OAuth (ของจริง):** ล็อกอินยืนยันตัวตนจริงผ่านการเชื่อมต่อ API ของ GitHub (เพียงกำหนดค่าใน `.env` หรือบนคลาวด์)
    *   **Local Mock OAuth 2.0 (ของจำลอง):** โหมด Demo สำหรับผู้ตรวจข้อสอบ รันเล่นออฟไลน์ได้ 100% ทันทีโดยไม่ต้องตั้งค่าใด ๆ (กรอกชื่อผู้ใช้สุ่มแล้วจำลองการส่ง Authorization Code ➔ Token Exchange ➔ UserInfo ครบถ้วนตามสเปก RFC 6749)
2.  **🗄️ ฐานข้อมูลคลาวด์ Cloudflare D1 (SQLite):**
    *   เก็บสถิติผู้เล่น ประวัติการชนะ/แพ้ และเซสชันการล็อกอินแบบถาวรบนคลาวด์เซิร์ฟเวอร์จริง
    *   ไม่มีปัญหาเรื่องไฟล์ JSON หายหรือฐานข้อมูลถูกล้างข้อมูลเมื่อทำการ Re-deploy
3.  **🔒 ความปลอดภัยระดับมาตรฐานอุตสาหกรรม:**
    *   **Secure Session Management:** เก็บรหัสผ่านจำลองและข้อมูลล็อกอินในคุกกี้ฝั่งหลังบ้านแบบ **HTTP-Only Cookie** ป้องกันการโดนขโมยผ่าน XSS
    *   **CSRF Protection:** มีระบบตรวจสอบความปลอดภัยด้วยพารามิเตอร์ `state` ป้องกันภัยคุกคามข้ามเว็บไซต์
4.  **🤖 บอท AI อัจฉริยะในโหมดผสม (Easy 50% / Medium 30% / Hard 20%):**
    *   ระบบจะสุ่มกลยุทธ์การเล่นของบอทในแต่ละตา เพื่อจำลองการเล่นกับคนที่มีความตึงมือต่างกันและช่วยเอื้อให้ทดสอบระบบคะแนนได้ง่ายขึ้น:
        *   **ระดับง่าย (Easy - 50%):** สุ่มเลือกตำแหน่งเดิน (ให้ผู้เล่นมีโอกาสชนะและเก็บแต้มได้ง่ายขึ้น)
        *   **ระดับปานกลาง (Medium - 30%):** บล็อกตำแหน่งที่คู่แข่งกำลังจะชนะ และกดชนะในช่องที่มีโอกาส
        *   **ระดับยากสุด (Hard - 20%):** ใช้ **Minimax Algorithm** วิเคราะห์ผลลัพธ์ล่วงหน้าเต็มตาราง บอทจะเล่นแบบไร้พ่าย (ทำได้ดีที่สุดคือเสมอ)
5.  **🏆 ระบบคะแนนและโบนัสสตรีค (Streaks):**
    *   ผู้เล่นชนะ: **+1 คะแนน** | ผู้เล่นแพ้: **-1 คะแนน** | เสมอ: **0 คะแนน**
    *   **โบนัสพิเศษ:** ชนะติดต่อกัน (Win Streak) ครบ 3 ครั้ง จะได้รับคะแนนโบนัสเพิ่มพิเศษอีก **+1 คะแนน** (พร้อมแสดงสัญลักษณ์ไฟ 🔥 และรีเซ็ตเริ่มนับรอบใหม่)
6.  **📊 แดชบอร์ดตรวจสอบคะแนน (Leaderboard):**
    *   มีหน้าจอแสดงอันดับคะแนนผู้เล่นทั้งหมดบนคลาวด์ พร้อมแถบค้นหาชื่อผู้เล่นแบบตอบสนอง (Real-time Filter)
    *   จัดเรียงข้อมูลแบบไดนามิกตามหัวตาราง (คะแนนรวม, ชนะ, แพ้, เสมอ หรือสตรีคสูงสุด)
7.  **🎨 การออกแบบระดับพรีเมียม (UI/UX) & Audio:**
    *   ธีมมืด (Dark Mode) ผสมผสาน Glassmorphism (การ์ดกระจกโปร่งแสง) พร้อมเอฟเฟกต์สะท้อนแสงและแอนิเมชันปุ่มเดินหมาก
    *   ระบบซาวด์เอฟเฟกต์ย้อนยุคด้วย **Web Audio API** สังเคราะห์คลื่นเสียงสดในหน้าเว็บ รันออฟไลน์ได้โดยไม่ต้องดาวน์โหลดไฟล์เสียงจากภายนอก

## 🛠️ โครงสร้างไฟล์และสถาปัตยกรรม (Architecture)

โปรเจกต์แยกตรรกะระบบ (Core Logic) และส่วนแสดงผล (UI) ออกจากกันอย่างชัดเจนตามหลักการ Clean Architecture:

*   📂 `src/app/` — หน้าจออินเทอร์เฟซและการทำ Routing ด้วย Next.js App Router
    *   📄 `page.tsx` — หน้าแรก Splash Page ตรวจสอบเซสชันและนำเข้าสู่ระบบ OAuth
    *   📂 `oauth/authorize/` — หน้า Consent Page สำหรับโหมดจำลองยืนยันสิทธิ์ข้อมูล
    *   📂 `oauth/callback/` — หน้าตัวรับสิทธิ์ (OAuth Callback) เพื่อทำการเชื่อมสิทธิ์เข้าระบบ
    *   📂 `game/` — หน้าสำหรับเล่นเกม OX แผงคะแนนและการปรับสตรีคบอท AI
    *   📂 `admin/` — หน้า Dashboard ตารางอันดับและเครื่องมือสืบค้นผู้เล่นทั้งหมด
*   📂 `src/app/api/` — ส่วนของหลังบ้าน API Routes (Edge Runtime ทั้งหมด)
    *   📂 `api/auth/config/` — คืนสถานะการเปิดใช้ GitHub OAuth หรือโหมดเดโม
    *   📂 `api/auth/session/` — จัดการและคืนค่าเซสชันของคุกกี้หลัก
    *   📂 `api/oauth/` — บริการย่อยสำหรับ Mock OAuth 2.0 Server (`authorize`, `token`, `userinfo`)
    *   📂 `api/game/score/` — ปรับปรุงสถิติและคะแนนสะสมลง Cloudflare D1
    *   📂 `api/admin/scores/` — ดึงข้อมูลคะแนนผู้เล่นทั้งหมดจาก Cloudflare D1
*   📂 `src/lib/` — ตรรกะประมวลผลหลัก
    *   📄 `db.ts` — ตัวจัดการระบบฐานข้อมูล เชื่อมต่อกับ **Cloudflare D1 Binding (`DB`)**
    *   📄 `game-utils.ts` — ตรรกะคำนวณชัยชนะ และระบบประมวลผลหมากเดิน AI (Minimax) สะดวกต่อการเขียน Unit Test

## 🚀 วิธีการติดตั้งและรันในเครื่อง (Local Setup)

1.  **ติดตั้ง dependencies:**
    ```bash
    npm install
    ```

2.  **การจัดการฐานข้อมูล D1 โลคอล (สำหรับการจำลองพัฒนา):**
    เพื่อสร้างฐานข้อมูล SQLite โลคอลในเครื่องและสร้างตาราง ให้รัน Migration:
    ```bash
    npx wrangler d1 migrations apply ox-game-db --local
    ```

3.  **เปิดรันเซิร์ฟเวอร์สำหรับพัฒนา (Development Server):**
    *   รันแบบปกติ (Next.js Dev Server):
        ```bash
        npm run dev
        ```
        เข้าใช้งานผ่านเบราว์เซอร์ที่ลิงก์: **[http://localhost:3000](http://localhost:3000)**
    
    *   รันตัวจำลองสภาพแวดล้อม Cloudflare Pages (Pages Dev Server):
        ```bash
        NPM_CONFIG_LEGACY_PEER_DEPS=true npm run preview
        ```

## ☁️ การบิลด์และการดีพลอยขึ้น Cloudflare Pages (Deployment)

เราได้ตั้งค่าสคริปต์การทำความสะอาดและบิลด์ที่ปลอดภัยต่อความปลอดภัยของรหัสผ่าน โดยใช้คำสั่งเดียวในการดีพลอยขึ้นระบบคลาวด์จริง:

```bash
NPM_CONFIG_LEGACY_PEER_DEPS=true npm run deploy
```

**สิ่งที่สคริปต์นี้ทำโดยอัตโนมัติ:**
1. เรียกใช้ `@cloudflare/next-on-pages` เพื่อคอมไพล์โปรเจกต์ Next.js ให้เป็นโครงสร้าง Worker
2. ทำการย้ายและคัดลอกไฟล์ที่แปลงแล้วไปยังโฟลเดอร์ที่เป็นกลางชื่อ `build_output`
3. ทำการล้างไดเรกทอรีชั่วคราว `.vercel` ออกจากเครื่องทั้งหมดทันที เพื่อความสะอาดของโปรเจกต์
4. ดีพลอยไฟล์ใน `build_output` ขึ้นสู่ **Cloudflare Pages** ของจริง

## 🔑 วิธีการเปิดใช้งานระบบ GitHub OAuth จริง (ไม่บังคับ)

หากต้องการเปลี่ยนจากระบบจำลอง (Mock Mode) เป็นระบบความปลอดภัยจริงผ่าน **GitHub Login**:

1.  เข้าไปที่ GitHub ➔ **Settings** ➔ **Developer Settings** ➔ **OAuth Apps** ➔ กด **Register a new application**
2.  ตั้งค่าพารามิเตอร์ดังนี้:
    *   **Homepage URL:** `http://localhost:3000` (หรือ URL ของ Cloudflare Pages ของคุณ)
    *   **Authorization callback URL:** `http://localhost:3000/oauth/callback` (หรือ `/oauth/callback` บน Cloudflare Pages)
3.  สร้างรหัสลับและคัดลอก **Client ID** และ **Client Secret**
4.  สร้างไฟล์ชื่อ `.env` ไว้ที่รากของโปรเจกต์ในเครื่อง และเพิ่มข้อมูลลงไป:
    ```env
    GITHUB_CLIENT_ID=รหัส_Client_ID_ของคุณ
    GITHUB_CLIENT_SECRET=รหัส_Client_Secret_ของคุณ
    ```
5.  หากต้องการให้ระบบบน Cloudflare Pages ทำงานได้ด้วย ให้ไปกรอกตัวแปรสภาพแวดล้อมนี้ที่เมนู **Settings** -> **Environment variables** บนแดชบอร์ด Cloudflare Pages ของคุณ

## 🧪 การรันชุดทดสอบ (Automated Unit Tests)

เราใช้ระบบ Test Runner ที่ติดตั้งในตัวมากับ Node.js ทำให้ผู้ตรวจสามารถทดสอบคุณภาพโค้ดและตรรกะเบื้องหลังได้ทันทีผ่านคำสั่งง่าย ๆ:

```bash
npm test
```

ชุดทดสอบจะรันและแสดงผลลัพธ์ผ่าน Terminal ยืนยันความถูกต้องของ **ระบบตรวจสอบผู้ชนะ 5 กรณี** และ **ระบบคำนวณหมากเดินของ AI บล็อก/ชนะ 2 กรณี**
